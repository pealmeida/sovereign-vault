## 3. Approval / OTP surfacing (regression re-verify)

- **Approval modal** surfaces **globally** (verified on the Settings page, not just Files) for Encrypt / Decrypt / Sign / CreateContainer / ListContainers. Confirms commit `87c8ff8` (event `vault://approval-request` + global host in `App.svelte`).
- **OTP modal** renders for OTP containers, displaying a vault-generated 6-digit code with "share it with the MCP caller".

## 4. Findings / bugs

1. **OTP is human-relay only over MCP.** The OTP modal *displays* a code but the MCP tool schemas (`vault_read`, `vault_create_container`, …) have **no `otp` parameter**, so a non-interactive caller cannot complete an OTP-gated op — the code can't be passed back. A scripted create on an OTP container therefore never completes. *Recommend: add an optional `otp` arg, or document OTP as interactive-client-only.*
2. **Approval-request retry storm.** After a gated `vault_list` from the OSS connector **timed out** (the synchronous client can't approve its own blocked call), the desktop kept surfacing fresh `ListContainers` approval modals faster than they could be dismissed — neither Approve nor Deny drained the queue. Required quitting the app to stop. *Likely a disconnected/timed-out MCP client reconnect-and-re-list loop. Recommend: dedupe/cancel pending approval requests when the requesting connection drops, and back off reconnect re-listing.*
3. **ANONYMIZED / ZKP / NATIVE** advertised in the mode enum but not implemented for live MCP — should be hidden from the create surface or marked experimental until implemented.
4. **No single-instance guard** (separate observation): Tauri spawns two same-named processes (main + WebView2) — not two app instances; killing one tears down both. A future `tauri-plugin-single-instance` would prevent accidental double-launch.

## Verdict

Core vault is usable across the three live modes (DIRECT, APPROVAL, OTP) and all 9 MCP tools function. Two issues to close before broad use: the OTP-over-MCP parameter gap and the approval retry storm. ANONYMIZED/ZKP/NATIVE remain unimplemented stubs.
