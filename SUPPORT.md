# Support

## Questions and usage discussions

For questions, how-to help, and general usage discussion, please use the
project's GitHub Discussions:

- <https://github.com/pealmeida/sovereign-vault/discussions>

Search existing discussions before opening a new one, and tag threads with
the most relevant category so others can find them.

## Security reports

Suspected security vulnerabilities must **not** be reported in the public
issue tracker or discussions. Instead, follow the private reporting process
described in [SECURITY.md](./SECURITY.md), which routes through GitHub Security
Advisories:

- <https://github.com/pealmeida/sovereign-vault/security/advisories/new>

## Bugs and feature requests

For reproducible bugs and concrete feature requests, open an issue in the
public issue tracker:

- Bugs: <https://github.com/pealmeida/sovereign-vault/issues/new>
- Features: <https://github.com/pealmeida/sovereign-vault/issues/new>

Please search for existing issues first, and include enough detail (steps to
reproduce, environment, version) so the problem can be triaged quickly.
